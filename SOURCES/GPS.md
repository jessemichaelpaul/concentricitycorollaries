## Pinpointed statements (VERBATIM)

### Target (a): slices and the slice decomposition, Section 1 (Introduction)

Introduction, third paragraph (ar5iv element id `S1.p3`):
> While the present work is set on general alternative ∗-algebras, for which we will give detailed preliminaries in Section 2, we can introduce the actors of the play by briefly overviewing the quaternionic case. Let ${\mathbb{S}}$ be the 2-sphere of square roots of $-1$ in the quaternionic space ${\mathbb{H}}$ and, for each $J\in{\mathbb{S}}$, let ${\mathbb{C}}_{J}\simeq{\mathbb{C}}$ be the commutative subalgebra of ${\mathbb{H}}$ generated by $J$. Let $\Omega$ be an open subset of the quaternionic space ${\mathbb{H}}$. A differentiable function $f:\Omega\rightarrow{\mathbb{H}}$ is called (Cullen or) slice regular if, for each $J\in{\mathbb{S}}$, the restriction of $f$ to $\Omega\cap{\mathbb{C}}_{J}$ is holomorphic with respect to the complex structure defined by left multiplication by $J$.

Introduction, fourth paragraph (ar5iv element id `S1.p4`; "(1)" is the displayed equation number, rendered inline here):
> The quaternionic space ${\mathbb{H}}$ can be decomposed as ${\mathbb{H}}=\bigcup_{J\in{\mathbb{S}}}{\mathbb{C}}_{J}$, with ${\mathbb{C}}_{J}\cap{\mathbb{C}}_{K}={\mathbb{R}}$ for every $J,K\in{\mathbb{S}}$ with $J\neq\pm K$. Thanks to this “slice” nature of ${\mathbb{H}}$, every slice regular function $f$ can be lifted to a unique holomorphic “stem” function $F:{\mathbb{R}}\otimes{\mathbb{C}}\rightarrow{\mathbb{H}}\otimes{\mathbb{C}}$, satisfying the relation $f(\phi_{J}(z))=\phi_{J}(F(z))$ (1) for each $z\in{\mathbb{R}}\otimes{\mathbb{C}}\simeq{\mathbb{C}}$ and for all $J\in{\mathbb{S}}$. Here $\phi_{J}$ denotes the mapping sending $a+b\sqrt{-1}\in{\mathbb{H}}\otimes{\mathbb{C}}$ to $a+Jb\in{\mathbb{H}}$.

Introduction, fifth paragraph (ar5iv element id `S1.p5`), the general-algebra slice-function definition sketch:
> This property is grounds for a generalized construction, with another alternative ∗-algebra $A$ instead of ${\mathbb{H}}$ and with an (appropriately defined) real algebraic subset ${\mathbb{S}}_{A}$ of $A$ instead of ${\mathbb{S}}$. An $A$-valued function $f$ that can be lifted to a function $F:{\mathbb{R}}\otimes{\mathbb{C}}\rightarrow A\otimes{\mathbb{C}}$ by means of formula (1) for all $J\in{\mathbb{S}}_{A}$ is called a slice function. If, moreover, the lifted function $F$ is holomorphic, then $f$ is termed slice regular.

Introduction, ninth paragraph (ar5iv element id `S1.p9`), the pointer to Section 11:
> In the final Section 11, we introduce the analogs of meromorphic functions, called (slice) semiregular functions. By means of the spherical Laurent expansions, we prove that semiregular functions over a circular domain form a real alternative ∗-algebra. The so-called tame elements of this algebra admit multiplicative inverses within the algebra.

### Supplementary: the formal slice decomposition, Section 2 (where §1's sketch is made rigorous)

Section 2 (ar5iv element id `S2.p7`; "(2)", "(3)", "(4)" are the displayed equation numbers, rendered inline here):
> For every $x\in A$, the trace $t(x)$ of $x$ and the (squared) norm $n(x)$ of $x$ are defined as $t(x):=x+x^{c}\quad\text{and}\quad n(x):=xx^{c}.$ (2) If we set ${\mathbb{S}}_{A}=\{x\in A\,|\,t(x)=0,n(x)=1\},$ (3) then the subalgebra ${\mathbb{C}}_{J}$ generated by any $J\in{\mathbb{S}}_{A}$ is isomorphic to the complex field. [...] Now, if we define the quadratic cone of $A$ as $Q_{A}:={\mathbb{R}}\cup\big{\{}x\in A\,\big{|}\,t(x)\in{\mathbb{R}},n(x)\in{\mathbb{R}},t(x)^{2}<4n(x)\big{\}}$ then $Q_{A}=\bigcup_{J\in{\mathbb{S}}_{A}}{\mathbb{C}}_{J}$. (4) Moreover, ${\mathbb{C}}_{I}\cap{\mathbb{C}}_{J}={\mathbb{R}}$ for every $I,J\in{\mathbb{S}}_{A}$ with $I\neq\pm J$.

Section 2, Definition 2.1 (ar5iv element id `S2.Thmtheorem1`), slice functions and slice preserving:
> **Definition 2.1.** Let $D$ be a nonempty subset of ${\mathbb{C}}$, invariant under the complex conjugation $z=\alpha+i\beta\mapsto\overline{z}=\alpha-i\beta$. A function $F=F_{1}+\imath F_{2}:D\longrightarrow A_{\mathbb{C}}$ with $A$-components $F_{1}$ and $F_{2}$ is called a stem function on $D$ if $F(\overline{z})=\overline{F(z)}$ for every $z\in D$ or, equivalently, if $F_{1}(\overline{z})=F_{1}(z)$ and $F_{2}(\overline{z})=-F_{2}(z)$ for every $z\in D$. If $\Omega:=\Omega_{D}$ then a function $f:\Omega\longrightarrow A$ is called a (left) slice function if there exists a stem function $F=F_{1}+\imath F_{2}:D\longrightarrow A_{\mathbb{C}}$ such that, for all $z=\alpha+i\beta\in D$ (with $\alpha,\beta\in{\mathbb{R}}$), for all $J\in{\mathbb{S}}_{A}$ and for $x=\alpha+\beta J$, $f(x)=F_{1}(z)+JF_{2}(z),$ In this situation, we say that $f$ is induced by $F$ and we write $f=\mathcal{I}(F)$. If $F_{1}$ and $F_{2}$ are ${\mathbb{R}}$-valued, then we say that the slice function $f$ is slice preserving. We denote by $\mathcal{S}(\Omega)$ the real vector space of slice functions on $\Omega$ and by $\mathcal{S}_{\mathbb{R}}(\Omega)$ the subspace of slice preserving functions.

(The trailing comma after the displayed formula $f(x)=F_{1}(z)+JF_{2}(z),$ directly followed by "In this situation" is as rendered by ar5iv.)

Section 2 (ar5iv element id `S2.p14`), the slice-preserving characterization:
