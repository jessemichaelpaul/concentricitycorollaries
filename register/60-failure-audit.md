# Failure audit and gate walk-around

Use this reference before accepting a gate, changing architecture, or
rewriting governing documentation.

## 1. Root failure

The recurring error is an inversion of determination:

```text
wrong:
generic categorical container
  → attach an action
  → attach A
  → install or read values

correct:
C1--C4 determine A's function/Möbius element
  → its evaluations are intrinsic value states
  → its geometry generates the relevant groupoids and transports
  → categorical machinery records and reads that action.
```

Once the container is chosen first, a constant carrier appears natural and
the missing coherence is misdiagnosed as new mathematics.

## 2. Repeated substitutions

Reject these shapes even when they compile:

- one function/Möbius element split into independent actions;
- a functor reduced to its object map;
- a naturality square reduced to one component arrow;
- the global action replaced by `AsectionSlice` or a chosen `baseWorld`;
- action-generated value states replaced by a generic carrier;
- a varying exponential action called constant because carrier types match;
- the Grothendieck total replaced by a product or direction-only total;
- the chosen zero system replaced by whole-total connectedness;
- literal finality replaced by generic zigzag invariance or pairwise arrow
  searches;
- intrinsic output replaced by a stored label;
- a theorem target turned into a field or definition.
- a framewise inverse image postponed until after the theorem whose role is
  only to assemble those inverse images across arrows;
- one transported action state split into “old” and “new” value evaluations;
- a whole-action preservation theorem replaced by a projected coordinate
  equality on one leg of its naturality square.
- the green all-`t` presentation reindexing silently identified with the
  accepted `F_A` state transport without proving their comparison at the
  certified inverse images.

## 3. Historical collapse

The old `β ⥤ SphereWorld` functor became constant because it selected a
single sphere object while Möbius transformations acted in its chart. It was
a legitimate sectional projection, not the action on all normalized inputs.

Later gates tried to repair that loss downstream:

- generic `Grpd` wrappers were introduced;
- local squares were promoted to the whole action;
- the total was treated as if it created the function/value unity;
- Gate 7 hunted zero-to-`N` arrows and used generic zigzags instead of
  reading the chosen cone and proving literal finality;
- housekeeping promoted the newest local success to canonical prose.

The local declarations were often genuine. Their promotion was false.

## 4. The geometric walk-around

Before giving a Lean type:

1. Name the C1--C4 infinite analytic object.
2. Identify the already-integrated function/Möbius element.
3. Treat normalized `s ∈ 𝕆*` as input to that element.
4. Walk vertically through GPV, winding, levels, and `N`.
5. Walk horizontally through orbit--stabilizer on objects and arrows.
6. Walk through every sphere direction using `SphereWorld` and `G₂`.
7. Read domain and codomain value states as evaluations.
8. Identify every naturality square relating these viewpoints.
9. Only then state the categorical type.
10. Only after the type is approved inspect or implement Lean packaging.

## 5. Gate acceptance

A green declaration closes a gate only if:

- its semantic subject is the one named by the gate;
- its object and arrow maps are generated by the same A-specific action;
- every claimed dimension is load-bearing;
- deleting a claimed supplier breaks the receipt or invalidates a required
  projection;
- no conclusion-shaped field or external label supplies the result;
- the terminal comparison is explicit.

Delete-and-rebuild audits are useful tripwires, but provenance is primary.
A syntactic occurrence of `A`, `SphereWorld`, or a square name does not prove
that the corresponding structure is semantically load-bearing.

## 6. Diagnostic language

Before declaring a gap:

1. verify that the exact current A-specific object is being used;
2. verify that no structure was projected away;
3. quote the exact unsatisfied Lean type;
4. exhaust existing naturality and groupoid structure;
5. distinguish a missing name from missing mathematics.

For an inverse-image/subdiagram gate, also enforce this order:

1. form the approved framewise inverse image of the approved semantic
   target;
2. apply the existing orbit--stabilizer/first-isomorphism and naturality
   squares to prove preservation;
3. restrict the existing map;
4. inherit identity and composition;
5. only then run the focused build and axiom receipt.

Do not launch a broad dependency build merely to investigate a speculative
projection. If the approved object has not yet been formed, stop the
diagnostic and return to the gate order.

Before declaring completion:

1. show the exact type;
2. show the object and arrow projections;
3. show the action's input/output provenance;
4. show the terminal comparison;
5. show the required build and axiom receipt.

## 6c. Two route-level diagnostics

**A trigger can live in a governing file.** A prohibition may accidentally
forbid the literal shape of an already-certified definition. When prose and
the kernel collide, do not force the code into the prohibition or diagnose
new mathematics. Sweep the register for the concept, compare it with the
live type, and correct the prose. Governing rules may forbid methods,
substitutions, or severed provenance; they must not forbid a goal merely
because of its syntactic shape.

**Independent routes discriminate route-local obstacles from
conclusion-based doubt.** A genuine obstruction must be stated at an exact
type and must be checked in the machinery of the route where it is alleged.
If the same vague “hidden gap” simply migrates from an action-groupoid route
to a finality route or a Thomason/bisimplicial route without an
object-specific failure in any of them, the doubt is attached to the
conclusion rather than the mathematics. Multiple routes do not replace a
kernel certificate; they prevent route-independent incredulity from being
misreported as a formal obstruction.

## 6d. Forensic record — the scratch route of 2026-07-26 (row 16, in full)

The artifact is preserved here because the file itself was deleted. It lived
at `/private/tmp/CResidueGateScratch.lean`, outside the repository; no
repository file, staged file, or governing document was modified, and no
broad build was run. Its body, in full:

```lean
theorem cResidue_preserved_scratch
    (A : ASection) {X Y : GreatCircle.Base} (f : X ⟶ Y)
    {x : AsectionActionFiber A X} (hx : IsCResidueState A X x) :
    IsCResidueState A Y ((AsectionActionTransport A f).obj x) := by
  rcases hx with ⟨z, hz, hcoordinate⟩
  change (z : OnePoint ℂ) = x.positioned.back.coordinate at hcoordinate
  refine ⟨z, hz, ?_⟩
  change
    (z : OnePoint ℂ) =
      (orbitStabilizerActionSquare A f).left.val
        x.positioned.back.coordinate
  rw [← hcoordinate]
```

**Where the obstruction came from.** `refine ⟨z, hz, ?_⟩` supplies the
witness **before** the square is used, and supplies the *same* `z`. That
choice asserts the transported coordinate is the very point it started at,
which leaves the residual goal

```text
(z : OnePoint ℂ) = left.val (x.positioned.back.coordinate)
```

— "the left leg fixes `z`." That is not the theorem, and the square does not
claim it. What the square gives is

```text
left • (m_X • input) = m_Y • (right • input),
```

so the transported coordinate is **a different point of the locus**,
produced by `m_Y ∘ right`. The obstruction was manufactured by the witness
choice, one step before any mathematics was consulted.

**The rule this yields.** *In an inverse-image preservation goal, the
witness is an output of the square, never an input to it.* Consume
`positioned_by_action` and `commutes` first; the new witness is whatever
they hand you. Choosing it up front silently converts a preservation
statement into a fixed-point statement.

This is the standard pattern with a Lean instance attached: a substitute
elaborates, produces an obstacle, and the obstacle belongs to the
substitute. Nothing about the whole square was learned, and nothing read off
this route carries any weight.
